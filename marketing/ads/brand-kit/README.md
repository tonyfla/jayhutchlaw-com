# Brand kit for ad creative

Assets for building ads that match the site.

## Colours

| Use | Hex |
|---|---|
| Navy (primary) | `#0e2947` |
| Deep navy | `#061a30` |
| Gold — decorative only | `#b38a4d` |
| Gold — text and buttons | `#8c6626` |
| Ivory background | `#faf8f3` |
| Paper background | `#f4f0e8` |

**`#b38a4d` fails contrast for text.** It is 3.4:1 on white. Use `#8c6626`
for any wording a viewer has to read, including the call-to-action.

## Type

- Headings: Libre Baskerville
- Body and buttons: DM Sans

Both are free from Google Fonts, and the exact files the site uses are in
`assets/fonts/`.

## Required on ads

Georgia advertising rules apply to social ads, not just the website. Confirm
with J. Hutchins what disclaimer each format needs, and record it in `ad.md`.
Do not state or imply a guaranteed result.
